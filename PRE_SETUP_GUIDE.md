# p2pool-go-VTC: Prerequisite Setup Guide

This guide walks through setting up the prerequisites to build and run `p2pool-go-VTC` on a Linux system (Ubuntu/Debian/Raspberry Pi OS).

---

## Step 1: Install Go

Install Go (1.20+ required, 1.22+ recommended):

**For Ubuntu / Debian / Raspberry Pi OS:**
```bash
sudo apt update
sudo apt install golang-go git -y
```

Verify your installation:
```bash
go version
```

---

## Step 2: Set Up `vertcoind`

`p2pool-go-VTC` communicates with a local, fully synced Vertcoin Core daemon (`vertcoind`) over JSON-RPC.

1. **Install Vertcoin Core:** Download the latest release from the [Vertcoin Core GitHub repository](https://github.com/vertcoin-project/vertcoin-core/releases) or install via Snap.
2. **Configure `vertcoin.conf`:** Enable the RPC server in `~/.vertcoin/vertcoin.conf` (or `~/snap/vertcoin-core/common/.vertcoin/vertcoin.conf` for Snap installs):
   ```ini
   server=1
   daemon=1
   txindex=1
   rpcuser=your_rpc_user
   rpcpassword=your_very_strong_rpc_password
   rpcallowip=127.0.0.1
   rpcbind=127.0.0.1
   ```
3. **Sync the Blockchain:** Start `vertcoind` and wait until `vertcoin-cli getblockchaininfo` shows `initialblockdownload: false` and `verificationprogress` at `0.9999+`.

---

## Step 3: Point to `verthash.dat`

The Verthash PoW algorithm requires the 1.2 GB `verthash.dat` dataset file generated by `vertcoind`.

Set the full path to your `verthash.dat` file inside `config.yaml`:
```yaml
# Standard install path:
verthash_dat_file: "/home/<your-user>/.vertcoin/verthash.dat"

# Or Snap install path:
verthash_dat_file: "/home/<your-user>/snap/vertcoin-core/common/.vertcoin/verthash.dat"
```

---

## Step 4: Configure Firewall (`ufw`)

Allow SSH, your P2P port (`9348`), and your multiplexed Stratum + Web UI port (`9172`):

```bash
sudo ufw allow ssh
sudo ufw allow 9348/tcp
sudo ufw allow 9172/tcp
sudo ufw enable
sudo ufw status
```

If you want external `p2pool-go-VTC` nodes outside your home LAN to connect to your node, forward TCP port `9348` on your router to your node's local IP address.

---

## Step 5: Build and Run `p2pool-go-VTC`

```bash
git clone [https://github.com/CADMonkey21/p2pool-go-VTC.git](https://github.com/CADMonkey21/p2pool-go-VTC.git)
cd p2pool-go-VTC
go mod tidy
cp config.example.yaml config.yaml
nano config.yaml
go build -o p2pool-go-vtc .
./p2pool-go-vtc
```
